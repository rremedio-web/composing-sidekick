# Composing Sidekick — shared assistant entry point

Read [AGENTS.md](AGENTS.md), then the [chat playbook](docs/CURSOR_CHAT_PLAYBOOK.md)
and the [knowledge guide](docs/KNOWLEDGE_GUIDE.md). These instructions apply to every
assistant using this workspace.

Read the owner's current request, their notes file (`store/NOTES.md`, if present) and
the current piece's registered notes directly. Generated summaries are not complete
substitutes. The musical references under `.claude/skills/sombra-brain/` are shared
templates; there is no separate Gemini knowledge database to maintain.

Distinguish symbolic analysis, measured audio features, actual listening, owner
statements and your interpretation. A successful listening receipt does not validate
every musical claim. Preserve source/version identity and use the existing recording
tools and research index described in the knowledge guide.
