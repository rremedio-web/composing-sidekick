# Challenge Deck

Draw from `references/cards.md`. Rules of the table:

1. **Apply, don't recite.** A card is only played when translated into a concrete
   move on the CURRENT material — name the clip, the bars, the notes. "Card: land
   on b6" becomes "MAIN 4, bar 39: end the phrase on the b6 instead of the b7."
2. **Pick by ailment.** `--stuck-on starting` → SPARK suit. `--stuck-on middle` →
   STRUCTURE suit. `--stuck-on finishing` → FINISH suit. No flag → any suit, but
   prefer PERSONAL cards (they bite deeper because they're true).
3. **Draw count**: default 1. If the owner says a number, deal that many — but apply
   each separately; a pile of unapplied cards is noise.
4. **Seeding**: if the owner gives a word, use it to pick (hash the word across the deck
   in that suit); otherwise choose the card whose bite best fits what's already in the
   room. Judgment over randomness — this deck has a dealer.
5. **The card can lose.** If the owner plays the move and it dies, say so and log what
   it taught. Cards are provocations, not assignments.
6. **Build and refresh the PERSONAL suit** from the corpus stats (rare cells,
   underused degrees, rare progressions come from live profile queries — regenerate
   the numbers rather than trusting the file's copies if they matter to the move). The
   public repository ships that suit as a recipe, not as cards.

Lineage note: the deck is in the spirit of oblique-strategy practice and of
problem-stage thinking (starting/progressing/finishing) — see
https://makingmusic.ableton.com/ for the book that frames those stages. All card
text here is ORIGINAL; never reproduce card text from copyrighted decks or books.

Kit routing: for a structured stage-diagnosis with a bounded exercise (timebox +
commit condition) use a process-coach skill if one is installed; this deck is for the
single provocation that breaks a tie. They compose: the coach names the block, a card
picks the fight.
